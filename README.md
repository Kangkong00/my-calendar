# 나만의 캘린더 · 설치·업데이트 안내

## ★ v3 데이터 창구 업데이트 (마지막 수동 작업, PC에서 약 5분)

이번 v3부터 데이터 창구에 중계 기능이 들어가서, 이후 화면 업데이트는 이 저장소에 바로 반영됩니다.

1. 앱스 스크립트 편집기에서 `Code.gs` 내용을 모두 지우고 이 저장소의 `apps-script/Code.gs`를 붙여 넣습니다.
2. `appsscript.json`도 이 저장소의 `apps-script/appsscript.json`으로 바꿉니다. (할 일·빠른 조회 권한이 추가됨)
3. 함수 목록에서 **setup** → **실행** → 새 권한 요청을 **허용**합니다. 비밀 키는 그대로입니다.
4. **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** (주소는 그대로).
5. 2~3분 뒤 폰의 앱을 완전히 닫았다가 다시 엽니다.

---

구성은 두 덩어리입니다.

- **apps-script/**: 구글 캘린더와 데이터를 주고받는 창구 (앱스 스크립트)
- **web/**: 폰과 PC에서 여는 화면 (GitHub Pages에 올림 → 구글 안내 문구 없음)

연결 전에도 web 화면은 **예시 데이터**로 돌아갑니다.

---

## A. 데이터 창구 만들기 (PC에서, 약 5분)

1. https://script.google.com 접속 → **새 프로젝트** → 이름을 `나만의 캘린더 API`로 바꿉니다.
2. 왼쪽 `Code.gs` 내용을 모두 지우고, `apps-script/Code.gs` 내용을 붙여 넣습니다.
3. 왼쪽 톱니바퀴 **프로젝트 설정** → `"appsscript.json" 매니페스트 파일 표시` 체크
   → 편집기로 돌아가 `appsscript.json` 내용을 `apps-script/appsscript.json`으로 바꿉니다.
4. 위쪽 함수 목록에서 **setup** 선택 → **실행**
   - 권한 요청이 뜨면: 계정 선택 → `고급` → `(안전하지 않음)으로 이동` → 허용
     (본인이 만든 스크립트라서 뜨는 경고입니다)
   - 아래 **실행 로그**에 나온 `비밀 키: …` 를 복사해 둡니다.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** → 나온 **웹 앱 URL**(…/exec)을 복사해 둡니다.

> 비밀 키가 남에게 알려졌다면 `resetKey` 함수를 실행해 새 키로 바꾸세요.
> 코드를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** (주소는 그대로 유지됩니다).

## B. 화면 올리기 (GitHub Pages, 약 5분)

1. https://github.com 로그인 → 오른쪽 위 **+ → New repository**
   - 이름: `my-calendar` · **Public** · Create
2. **uploading an existing file** → `web/` 폴더 안의 파일 5개를 끌어다 놓기
   (`index.html`, `manifest.json`, `icon-180.png`, `icon-512.png`, `icon.svg`) → **Commit changes**
3. **Settings → Pages** → Source: `Deploy from a branch` · Branch: `main` / `(root)` → **Save**
4. 1~2분 뒤 주소: `https://내아이디.github.io/my-calendar/`

> 주소와 비밀 키는 코드에 들어 있지 않습니다. 저장소가 공개여도 내 일정은 보이지 않습니다.

## C. 폰에 설치

1. 아이폰 **사파리**로 B-4 주소 열기 → **공유 → 홈 화면에 추가** → 가죽 다이어리 아이콘이 생깁니다.
2. 앱을 열고 **설정** → `웹 앱 주소`(A-5)와 `비밀 키`(A-4) 입력 → **저장하고 연결 확인**
3. "연결되었습니다"가 뜨면 끝. 이후로는 실제 구글 캘린더 일정이 보입니다.

## D. 회사 PC

같은 주소(B-4)를 열고, C-2처럼 주소와 키를 한 번 입력합니다.
github.io 주소가 막혀 있으면 알려 주세요. 다른 방법으로 바꾸겠습니다.

## 들어 있는 기능 (v2)

- 월간: 종일 일정 = 글자 막대, 시간 일정 = 색 칩, 날짜 누르면 하루 시간표
- 주간: 0~24시 한 화면, 빈 칸을 누르면 그 시간으로 새 일정
- 새 일정: 캘린더 선택, 30분 칩 + ±5·±10분, 소요 시간 칩, 반복, 알림(기본 꺼짐), 새 카테고리 만들기
- 복제: 일정 상세 → 복제하기 / 하루 시간표 → 일정 가져오기(어제·지난주 같은 요일·지난달 같은 날·날짜 고르기)
- 삭제: 직접 만든 일반 일정만 (반복 일정·캘린더 삭제는 구글 캘린더에서)
- 할 일: 구글 Tasks 연동, 빠른 추가(오늘·내일·다음 주 월·날짜 없음), 밀린 일 "모두 오늘로", 금박 체크 애니메이션
- 간트: 월·분기·1년 보기, 업무·공부·개인 필터, 단계별 완료 체크, 새 계획 만들기
- 설정: 연결, 월간에서 숨길 캘린더, 대괄호 태그 숨기기, 캘린더에 계획 막대 보기

## PC에 설치하기 (v3.21~)
1. PC의 **크롬** 또는 **엣지**로 https://kangkong00.github.io/my-calendar/ 를 엽니다.
2. 주소창 오른쪽 끝의 **설치 아이콘**(모니터에 화살표 모양)을 누르고 → **설치**.
   - 아이콘이 안 보이면: 크롬은 오른쪽 위 ⋮ → **전송, 저장, 공유 → 페이지를 앱으로 설치**, 엣지는 ⋯ → **앱 → 이 사이트를 앱으로 설치**.
   - 앱 설정 화면의 **'이 기기에 앱 설치'** 버튼으로도 됩니다(크롬·엣지에서 설치 가능할 때만 보임).
   - 맥 사파리: 메뉴 **파일 → Dock에 추가**.
3. 바탕화면·시작 메뉴에 '캘린더' 앱이 생깁니다. 창 크기를 바꾸거나 최대화·전체 화면(F11)으로 써도 화면이 맞춰집니다.
4. **구글 연결 옮기기**: 휴대폰 앱 설정 → '다른 기기용 연결 코드 복사' → (카톡 나에게 보내기 등 본인만 보는 곳으로) PC로 옮김 → PC 앱 설정의 **주소 칸에 붙여 넣고** '저장하고 연결 확인'. 옮긴 뒤 메시지는 지워 주세요(비밀 키가 들어 있음).
- PC 단축키: ←/→ 이전·다음 달(주), Esc 창 닫기.
