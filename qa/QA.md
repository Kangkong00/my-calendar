# 자체 검수 규칙 (모든 수정·추가 때 반드시)

전달 전에 아래를 모두 통과해야 한다. 통과 못 하면 고치고 다시 돌린다.

## 1. 자동 검수 (`python3 qa/qa.py http://localhost:8765/index.html`)
- 화면 크기 4종(320×693 확대 모드, 375×667, 390×844, 430×932)에서 모든 화면·시트를 연다
  - 월간, 하루 시간표, 주간, 새 일정(시작·종료 시간, 새 카테고리, 알림), 일정 상세·수정, 일정 가져오기·여러 날,
    할 일, 할 일 메모(긴 내용·맨 아래·큰 글씨), 간트·계획 수정·새 계획, 설정, 분석(월간·주간·지난주), 주간 헤더
- 검사 항목: 누르는 요소끼리 겹침, 상자 밖으로 넘침, 가로 스크롤, 화면 밖 버튼, 잘린 글자, 스크립트 오류
- 긴 제목·긴 메모(30줄)·큰 글씨 같은 극단값으로 시험한다

## 2. 기능 검수
- 새 기능은 예시 데이터로 끝까지 실행(저장 → 다시 열기 → 값 확인)
- 저장 형식이 바뀌면 왕복 시험(저장한 것을 다시 불러와 같게 보이는지)
- 터치로 시험(has_touch), 연속 탭·스크롤 후 탭

## 2-1. 아이폰 홈 화면 앱 재현
- qa.py가 자동으로 함: 창 797/화면 844·안전영역 47/34 흉내(+320·430 기기)로 앱 높이=화면 높이, 하단 바 끝=화면 끝, + 버튼 아래 14~30px, 시트 끝=화면 끝 확인 (CLAUDE.md 7장)
- PC 1280×800: 앱 폭 480 이하 가운데, 겹침·넘침 없음 (qa.py 자동)
- 캘린더↔할 일 연결·시작 화면 (qa.py 자동): 마지막 탭이 할 일이어도 월간으로 시작, 월간 표시 개수=마감 할 일 개수, 하루 시트 체크 → 시트·월간 둘 다 줄어듦, 할 일 눌러 메모 열림
- 반복 할 일 (qa.py 자동): 처음 등록에서 날짜 고르기+매주 → 저장값 확인·입력 글자 유지·추가 후 '안 함' 복귀, 매일 반복 저장 → ↻ 표시·표식 숨김, 다음 날 흉내 → 새 회차 1개(다시 불러도 중복 없음), 밀린 회차 → 오늘로 옮김, 삭제 → 반복 멈춤, 규칙 계산(평일·매주·매월 말일)
- 색 규칙: 연두색은 AI 문장 전용 — 예시 모드(키 없음)에서 할 일 응원이 옅은 갈색인지 눈으로 확인
- 새 오버레이에 position:fixed 쓰지 않았는지 확인

## 3. 눈으로 검수
- 자동 검수 스크린샷을 직접 열어 디자인·정렬·여백을 본다 (특히 새로 바뀐 화면)
